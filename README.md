# 日々是衒学

毎日ひとつ、知ると世界の見え方が少し変わる言葉を教えてくれる、スマホ向けの衒学ワード帳です。
日常生活すべてをひけらかしの舞台にするために。

各語には次の4つが付いています。

- **ひとことで** … 意味の要約
- **由来** … 名前の出どころや背景の物語
- **見え方が変わるところ** … 知ると何が違って見えるか
- **使ってみる** … 日常会話での使い方の例

## 画面

下のタブで3つの画面を切り替えます。

- **今日** … 今日の言葉。左右の矢印か、カードの左右スワイプで過去の日にさかのぼれます（未来の日には進めません）。
- **これまで** … これまでに出た言葉の一覧と、「知ってた／知らなかった」の記録。
- **ことば帳** … 全語彙。ジャンルで絞り込めて、まだ登場していない言葉には登場日が出ます。

## スマホに入れる

GitHub Pages などで公開したページを開き、ホーム画面に追加するとアプリとして使えます（PWA）。

- iPhone：Safari の共有ボタンから「ホーム画面に追加」
- Android：Chrome のメニューから「ホーム画面に追加」（「インストール」と出ることもあります）

一度開けば、オフラインでも動きます。GitHub Pages で公開するには、リポジトリの Settings → Pages でこのブランチのルートを公開元に指定してください。

## 開発

ビルドは不要です。

```sh
npm install # テスト用の形態素解析（kuromoji）を入れる
npm start   # http://localhost:3000 で配信（serve を使用）
npm test    # 日付計算・文節の区切り・語彙データの検査
```

- 日付は端末の時計で切り替わります。第1日は 2026年10月2日（`js/daily.js` の `START`）。
- 語を出し尽くしたら先頭に戻ります。
- 「知ってた／知らなかった」はブラウザの localStorage にだけ保存されます。
- アプリ本体のファイルを変えたら、`sw.js` の `CACHE` の版を上げてください（古いキャッシュが消えます）。

### 改行の位置

日本語は文節ごとに `<wbr>` を入れ、CSS の `word-break: keep-all` で単語の途中では折り返さないようにしています。文節の区切りには Google の [BudouX](https://github.com/google/budoux)（Apache License 2.0）を `js/vendor/budoux-ja.js` に同梱して使っています。見出し語はさらに、「・」「＝」「／」の後と助詞「の」「と」「は」「を」の後だけで折り返し、一行に収まらない場合は文字を少し小さくします。

BudouX は「投げ落と｜される」のように単語の途中で区切ることがあるので、そうなる語を `js/phrase.js` の `KEEP_TOGETHER` に並べて、その内側では折り返さないようにしています。`npm test` は形態素解析（kuromoji）で全語彙の区切りを調べ、単語の途中で区切っている箇所があれば、足すべき語を表示して失敗します。

## 語の選び方

1. 名前だけで少し引っかかる
2. 由来に物語がある
3. 知るとニュース・歴史・人間関係の見え方が少し変わる
4. 教科書っぽすぎない

「囚人のジレンマ」「シュレーディンガーの猫」ほど有名な語や、すでに知っている語（「テセウスの船」「ウロボロス」など）は外しています。外す語の一覧は `test/words.test.js` の `EXCLUDED` にあり、テストで混入を防いでいます。

ジャンルは 歴史・社会・心理・哲学/思考・文学・芸術・宗教/神話・科学・数理/情報・言葉・建築/都市・医学/からだ・政治/法・経済/お金 の14種類、全155語です。

## 語を足すとき

語彙は `data/words.js` の `WORDS` 配列にあります。**配列の並びがそのまま出題順**なので、新しい語は原則として末尾に足してください。途中に挟むと、過去の日付に表示される語がずれます（第2日以降を組み直した2026年10月2日の追加のように、まだ出ていない日だけを並べ替えるのは問題ありません）。

`npm test` は次のことを確かめます。

- 必須項目（`id` `term` `original` `genre` `gist` `story` `lens` `flex`）がそろっている
- `id` が英小文字・数字・ハイフンだけで、重複しない（URLの `#w-<id>` に使う）
- ジャンルが `GENRES` のどれかである
- 隣り合う日でジャンルが続かない（周回の切れ目も含む）
- 外すと決めた語が入っていない
- 見出し語の折り返せない一続きが11文字以内（幅320pxの画面でも一行に収まる）
- 本文の文節の区切りが単語の途中に入っていない（kuromoji が必要。未インストールなら飛ばす）

## 構成

```
index.html             画面
style.css              見た目（ライト／ダーク両対応）
manifest.webmanifest   ホーム画面に追加するための設定
sw.js                  オフライン用のサービスワーカー
icons/                 アプリのアイコン
js/daily.js            日付 ⇔ 第何日 ⇔ その日の語
js/phrase.js           日本語を文節で区切って <wbr> を入れる
js/vendor/budoux-ja.js 文節の区切り（BudouX）
js/app.js              画面の描画と操作
data/words.js          語彙データ
test/                  node:test によるテスト
```
