# 日々是衒学

毎日ひとつ、知ると世界の見え方が少し変わる言葉を教えてくれる、日めくり型の衒学ワード帳です。
日常生活すべてをひけらかしの舞台にするために。

各語には次の4つが付いています。

- **ひとことで** … 意味の要約
- **由来** … 名前の出どころや背景の物語
- **見え方が変わるところ** … 知ると何が違って見えるか
- **ひけらかすなら** … 日常会話での使い方の例

## 使い方

ビルドは不要です。`index.html` をブラウザで開けばそのまま動きます。

```sh
npm start   # http://localhost:3000 で配信（serve を使用）
npm test    # 日付計算と語彙データの検査
```

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で、このブランチのルートを公開元に指定してください。

- 日付は端末の時計で切り替わります。第1日は 2026年10月2日（`js/daily.js` の `START`）。
- 過去の日にはさかのぼれますが、未来の日には進めません。ただし「全語彙」を開くと、これから出る語も見られます。
- 「知ってた／知らなかった」の記録はブラウザの localStorage にだけ保存されます。難易度の調整の目安に使えます。
- 語を出し尽くしたら先頭に戻ります。

## 語の選び方

1. 名前だけで少し引っかかる
2. 由来に物語がある
3. 知るとニュース・歴史・人間関係の見え方が少し変わる
4. 教科書っぽすぎない

「囚人のジレンマ」「シュレーディンガーの猫」ほど有名な語や、すでに知っている語（「テセウスの船」「ウロボロス」など）は外しています。外す語の一覧は `test/words.test.js` の `EXCLUDED` にあり、テストで混入を防いでいます。

ジャンルは 歴史・社会・心理・哲学/思考・文学・芸術・宗教/神話・科学・数理/情報・言葉 の10種類です。

## 語を足すとき

語彙は `data/words.js` の `WORDS` 配列にあります。**配列の並びがそのまま出題順**なので、新しい語は必ず末尾に足してください。途中に挟むと、過去の日付に表示される語がずれます。

`npm test` は次のことを確かめます。

- 必須項目（`id` `term` `original` `genre` `gist` `story` `lens` `flex`）がそろっている
- `id` が英小文字・数字・ハイフンだけで、重複しない（URLの `#w-<id>` に使う）
- ジャンルが `GENRES` のどれかである
- 隣り合う日でジャンルが続かない（周回の切れ目も含む）
- 外すと決めた語が入っていない

## 構成

```
index.html        画面
style.css         見た目（ライト／ダーク両対応）
js/daily.js       日付 ⇔ 第何日 ⇔ その日の語
js/app.js         画面の描画と操作
data/words.js     語彙データ
test/             node:test によるテスト
```
